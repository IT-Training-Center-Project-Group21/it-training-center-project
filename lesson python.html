Python

Python is an easy to interpret and high-level object-oriented programming language with easy-to-read syntax.

Lesson 1: Introduction to Python and basic Syntax

Syntax: Python uses clean and simple syntax. It uses spaces (Indentation) to define code blocks instead of curly braces {}.

Variables & Printing: You can create variables directly without declaring types, and use print() to show output.

Basic Data Types: Numbers, text (Strings), and Booleans (True/False).

Example:

# 1. Variables and Data Types
name="Dara"         # String
age =22            # Integer
gpa =3.8           # Float
is_passed =True     # Boolean

# 2. Printing Output
print("Name:", name)
print("Age:", age)

# 3. Simple Condition using Indentation
if age >= 18:
print("You are an adult.") # Indented with 4 spaces
else:
    print("You are a minor.")

Lesson 2: Data Structures (Lists, Dictionaries, Tuples, Sets)

List ([]): Ordered and changeable collection of items.

Dictionary ({key: value}): Stores data in key-value pairs.

Tuple (()): Ordered but cannot be changed (immutable).

Set ({}): Unordered collection of unique items (no duplicates).

Example:

# 1. List (Changeable)
fruits = ["apple", "banana", "cherry"]
fruits.append("orange") # Add new item
print("List:", fruits) # Output: ['apple', 'banana', 'cherry', 'orange']

# 2. Dictionary (Key-Value)
student = {
    "name": "Sophea",
    "score": 95,
    "city": "Phnom Penh"
}
print("Student Name:", student["name"]) # Output: Sophea

# 3. Tuple (Unchangeable)
(11.5564, 104.9282)

# 4. Set (Unique items only)
{1, 2, 2, 3, 4, 4}
print("Set:", numbers) # Output: {1, 2, 3, 4}
