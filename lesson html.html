HTML

Hypertext Markup Language

HTML is the standard markup language for documents designed to be displayed in a web browser.

1. Hypertext Markup Language (HTML)

Lesson 1: Introduction to HTML and the basic structure of web documents.

HTML (Hypertext Markup Language) is the key language for creating structure and layout of website pages. An HTML document starts with <!DOCTYPE html> and contains tags such as <html>, <head>, <title>, and <body> which organize elements and contain visible content on the screen.

Example:
index.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to my first website!</h1>
    <p>This is the text displayed on the web screen.</p>
</body>
</html>

Lesson 2: Using HTML tags for headings, paragraphs, and lists.

The display of text on the website must use the tag according to its role:

  • Headings (<h1> to <h6>): Used for headings from large to small.
  • Paragraph (<p>): Used to write paragraph text.
  • Lists (<ul>, <ol>, <li>): Used to create structured bulleted or numbered lists.
Example:
index.html 
<!-- Title / Heading -->
<h1>Main Heading Heading 1</h1>
<h2>Subheading Heading 2</h2>

<!-- Paragraph -->
<p>Learning Web Development helps us create websites on our own.</p>

<!-- Unordered List -->
<h3>Skills we learn:</h3>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
</ul>

<!-- Ordered List -->
<h3>Learning steps:</h3>
<ol>
    <li>Learn HTML Fundamentals</li>
    <li>Learn Styling with CSS</li>
</ol>

Lesson 3: Uploading images, videos, and links (Links & Media)

To make the website interactive, context is added to link pages along with images and videos:

  • Anchor Tag (<a>): Uses href attribute to link context to various sites.
  • Image Tag (<img>): Uses src attribute for image sources and alt for displaying alternate text when the image fails to load.
  • Video Tag (<video>): Used to play video with controls attribute.
Example:
index.html 
<!-- Link -->
<a href="https://www.google.com" target="_blank">Go to Google</a>

<!-- Image -->
<img src="profile.jpg" alt="Sample photo" width="200" height="200">

<!-- Video -->
<video width="320" height="240" controls>
    <source src="sample-video.mp4" type="video/mp4">
    Your browser does not support this video.
</video>

Lesson 4: Creating a form to collect information from users

Web forms permit user interaction to collect data from users, with serving forms designed to contain standard components like <input>, <label>, <textarea>, and <button>.

Example:
index.html 
<form action="/submit" method="POST">
    <!-- Name Input Box -->
    <label for="fullname">Full Name:</label>
    <input type="text" id="fullname" name="fullname" placeholder="Enter name..." required>

    <!-- Email Input Box -->
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" placeholder="example@gmail.com" required>

    <!-- Message Input Box -->
    <label for="message">Your message:</label>
    <textarea id="message" name="message" rows="4" cols="30"></textarea>

    <!-- Send button -->
    <button type="submit">Send Message</button>
</form>

Lesson 5: Using Semantic HTML5 for organizing website layouts.

Semantic HTML is the usage of HTML tags that have a clear meaning for each part of the website, such as <header>, <main>, <section>, <article>, and <footer>. The use of Semantic HTML tags improves search engine optimization (SEO) and helps web browsers understand the website layout structure.

Example:
index.html 
<!DOCTYPE html>
<html lang="en">
<body>

    <!-- Header Section -->
    <header>
        <h1>IT Website</h1>
        <nav>
            <a href="#">Home</a> | 
            <a href="#">Courses</a>
        </nav>
    </header>

    <!-- Main Content Section -->
    <main>
        <article>
            <h2>Latest News</h2>
            <section>
                <h3>HTML5 Semantic Structure</h3>
                <p>Semantic HTML tags keep code organized and easy to manage.</p>
            </section>
        </article>
    </main>

    <!-- Footer Section -->
    <footer>
        <p>© 2026 All rights reserved by MyWebsite</p>
    </footer>

</body>
</html>

Lesson 6: Structuring Data with HTML Tables

HTML tables allow developers to arrange data into rows and columns using <table>, <tr>, <th>, and <td>.

Example:
index.html 
<table>
    <!-- Table Header -->
    <tr>
        <th>Course</th>
        <th>Duration</th>
    </tr>
    <!-- Table Row 1 -->
    <tr>
        <td>HTML5 Fundamentals</td>
        <td>2 Weeks</td>
    </tr>
</table>
