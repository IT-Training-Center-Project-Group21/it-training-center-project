SQL

Structured Query Language

(SQL) is a standardized programming language used to manage, manipulate, and retrieve data stored in relational databases.

Lesson 1: Basics of Database and SQL Language

Database: A system that stores data in tables with rows and columns.

RDBMS: Software used to manage relational databases (e.g., MySQL, PostgreSQL).

SQL Commands: Commands used to create, read, update, and delete data in a database.

Example:

id name age city
1 Sokha 25 Phnom Penh
2 Bopa 18 Siem Reap
3 Dara 30 Phnom Penh

Lesson 2: Data Structures (Lists, Dictionaries, Tuples, Sets)

SELECT: Chooses columns to view.

WHERE: Filters data based on conditions.

ORDER BY: Sorts results (ASC for ascending, DESC for descending).

LIMIT: Restricts the number of rows returned.

Example:

SQL

-- Select names and ages of users from Phnom Penh, sorted by age

SELECT name, age

FROM users

WHERE city = 'Phnom Penh'

ORDER BY age DESC

LIMIT 2;


-- Output Result:

-- Dara (30)

-- Sokha (25)
