UX&UI

User Experience User Interface

(UX): Focuses on the overall journey, structure, and functionality.(UI): Focuses on the visual elements and presentation.

Lesson 1: The basics of UX/UI Design and the differences between UX and UI

UX: Focuses on user satisfaction, ease of use, and overall experience (Function & Structure).

UI: Focuses on the visual elements like colors, fonts, layout, and buttons (Look & Feel)

Example:

UX Example: Arranging the "Buy Now" button in a visible place and clicking buy to make it as fast as 2-3 clips (2-click checkout process).

UI Example: Selecting the "Buy Now" button color as green with white lettering and a nice shade.

Lesson 2: User Research and Creating User Personas & Wireframes

User Research: Gathering information about user needs and problems

User Persona: Creating fictional characters representing target users.

Wireframe: Creating simple black-and-white structural sketches of a webpage or app layout.

Example:

User Persona Sample:

  • Name: Sokni (Age 22, Student)
  • Goal: Wants to buy books online quickly during break time.
  • Pain Point: Websites with complicated registration forms take too long.
