CSS

Cascading Style Sheets

(CSS) is a style sheet language used for specifying the presentation and styling of a document.

Lesson 1: CSS (Selectors, Colors, & Typography)

Khmer: CSS is used to define HTML elements' style, color, and style.

Selectors: used to select an element (through tag, class ., or ID #)

Colors: set text color or background color (color, background-color) color

Typography: Set the font-family, font-size etc.

Simple English: CSS styles HTML elements. You use Selectors to target elements, Colors for text and background, and Typography for fonts and text sizes.

Example:

HTML
<!-- HTML -->
<h1 class="main-title">Heading (Title)</h1>
<p id="description">Descriptive text (Description text)</p>
<!-- CSS -->
<style>
/* Element Selector */
body {
font-family: Arial, sans-serif;
background-color: #f4f4f4;
}

/* Class Selector */
.main-title {
color: #0066cc;
font-size: 28px;
}

/* ID Selector */
#description {
color: #333333;
font-size: 16px;
}
</style>

Lesson 2: Understanding Box Models (Margin, Padding, Border, Content)

Khmer: All elements in HTML are treated as a box with 4 sections:

Content: the area to display the content (text/image).

Padding: the blank between the content and the border inside.

Border: the wall around the content and Padding.

Margin: The empty space between one box and another (external).

Simple English: Every HTML element is a box. It has 4 parts:

Content: The actual text or image.

Padding: Space inside the border.

Border: The line around the padding and content.

Margin: Space outside the border.

Example:

CSS
.card {
width: 300px;            /* Content width */
padding: 20px;          /* Inner space */
border: 2px solid #333;  /* Border line */
margin: 15px;           /* Outer space */
background-color: white;
}
